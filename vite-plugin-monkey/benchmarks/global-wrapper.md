# 静态外部依赖直接包装（2026-11-06）

> 历史实验记录，描述当轮实现与测量结果，不代表当前行为或测试状态。临时源码快照已于 2026-11-07 清理，原复现命令不再可用；当前实现见 [Architecture](../ARCHITECTURE.md)。

本轮把单 chunk 快速路径扩展到所有静态导入均映射到已配置全局变量的情况。生成代码直接把全局对象传给包装函数，不包含模块注册、链接、加载和执行状态管理。默认拆分与多 chunk 模块系统保持原有处理方式，没有恢复 IIFE 二次构建或增加依赖。

只有命名导入时直接读取原全局对象的属性。默认/命名空间导入使用带 getter 的兼容对象，保留 default 优先、否则取全局值本身的规则，不修改被冻结的对象或函数。重复导入同一模块只计算一次全局表达式，并共享兼容对象。副作用导入保留 `@require`，不读取未使用的全局绑定。

动态导入、未知静态导入、导出声明及 import.meta 继续使用现有模块系统。本轮没有扩展这些情况，也没有改变 Worker 的模块协议。

## 产物对比

环境为 Node 26.13.0、Vite 8.3.0、Rolldown 1.2.7、Windows x64。同进程、同临时工程，两次预热后交替执行两个实现，各采样九次，取中位数；`build.write=false`。体积包含 userscript 元数据。

| 导入形式     | 压缩体积：之前 → 之后 | gzip：之前 → 之后 |       构建中位数 |
| ------------ | --------------------: | ----------------: | ---------------: |
| 命名导入     |         2,317 → 181 B |     1,043 → 162 B | 20.33 → 19.78 ms |
| 默认导入     |         2,319 → 470 B |     1,043 → 311 B | 12.19 → 12.45 ms |
| 命名空间导入 |         2,283 → 462 B |     1,027 → 309 B | 17.45 → 18.24 ms |

命名导入缩小约 92%，并恢复到原 IIFE 基准的 181 B；实际脚本主体为：

```js
(function (e) {
  'use strict';
  globalThis.answer = e.answer;
})(FixtureLib);
```

关闭压缩时，三种形式分别由 5,362 → 234 B、5,364 → 677 B、5,325 → 669 B。默认与命名空间导入仍有兼容对象的开销，但不再携带模块运行时。

本次主要收益是体积。各例耗时变化较小，默认/命名空间样例略慢，不能宣称整体构建加速。完整样本、产物哈希、源码哈希与其他场景数据见 [global-wrapper.json](./global-wrapper.json)。节点端源码增加 97 个非空行（4,552 → 4,649），文件数仍为 70；改动复用了已依赖的 Vite 导入引用转换和 MagicString。

## 语义与验证

- 命名导入保持 live reads、别名与局部遮蔽；默认和命名空间属性也通过 getter 读取。
- 同步入口和同步错误不被 Promise 延后；真实 TLA 之前的代码立即执行。
- 默认导入、命名空间导入覆盖原始值、null/undefined、普通对象、冻结对象、冻结函数和 Symbol 属性，且不修改源值。
- 普通调用、可选调用及模板标签调用保持接收者语义。Vite 的导入重写及 Terser 对逗号表达式标签的处理曾导致标签重新绑定接收者；现在在替换值求值前捕获标签函数，通过轻量转发函数无接收者调用。测试覆盖替换值修改原函数时的求值顺序，以及命名空间成员调用应保留接收者的情况。
- 非浏览器测试合计 250 项通过；生产浏览器 28 项、模块契约浏览器 6 项通过。
- TypeScript、两套公开声明检查、ESLint 和 diff 空白检查通过。
- 发布构建、postbuild、pnpm pack 通过；发布入口验证了同步默认/命名空间导入、属性更新与压缩开关。

开发模式未在本轮重复运行；此前空 CSS HMR 超时不属于本次改动范围。快速路径仍依赖 Vite `moduleRunnerTransform` 的导入引用改写，不是独立的完整 ESM 编译器。

基线为本轮开始前的未提交源码快照，已经包含上一轮取消 IIFE 二次构建的改动。JSON 中的 `baselineRevision` 仅表示当时 HEAD，不能用于还原已清理的快照。样本和哈希继续保存在 JSON 中。
